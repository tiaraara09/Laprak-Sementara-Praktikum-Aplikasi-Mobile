📘 Laporan Praktikum 4: Navigasi & Passing Data

Pengembangan Pergerakan Antar Layar dan Pengiriman Data

Tiara Azizah | Informatika 24 - Universitas Andalas

📖 BAB I: Pendahuluan

1.1 Tujuan Praktikum

Praktikum ini memiliki beberapa tujuan utama terkait pergerakan antar layar pada aplikasi, yaitu:

  • Menerapkan Navigator.push untuk berpindah ke layar baru.
  • Menggunakan Navigator.pop untuk menutup layar setelah suatu aksi selesai dilakukan.
  • Mengirim data dengan tipe data seperti String dan int antar layar melalui Constructor.

1.2 Alat dan Lingkungan Kerja

Flutter SDK VS Code / Android Studio Emulator / Device

📖 BAB II: Dasar Teori

Navigasi di dalam Flutter dikelola oleh widget bernama Navigator yang bekerja dengan konsep Stack atau tumpukan kartu:

  • Push (Maju): Digunakan untuk meletakkan halaman baru di tumpukan paling atas sehingga layar akan berpindah ke halaman tersebut.
  • Pop (Mundur): Digunakan untuk menghapus atau menutup halaman teratas untuk kembali ke halaman sebelumnya.
  • Passing Data: Dalam melakukan pengiriman data (passing data) antar halaman, halaman penerima (misalnya Halaman B) harus menyiapkan variabel penampung bertipe final dan sebuah Constructor. Penggunaan kata kunci required di dalam Constructor menandakan bahwa data tersebut wajib diisi ketika halaman dipanggil.

🛠️ BAB III: Langkah Kerja & Implementasi

Dalam praktikum ini, struktur proyek dibagi menjadi 4 file terpisah di dalam folder lib untuk mensimulasikan arsitektur aplikasi yang rapi.

📌 3.1 main.dart

Berfungsi sebagai file utama untuk menjalankan aplikasi dengan konfigurasi tema warna merah (Colors.red) yang memuat DashboardScreen pertama kali.

📌 3.2 dashboard_screen.dart

Halaman utama (dashboard) yang menampilkan sisa saldo dan daftar transaksi. Saat item transaksi atau tombol Floating Action Button diklik, aplikasi menggunakan Navigator.push untuk berpindah halaman dan sekaligus mengirimkan data transaksi (seperti judul, jumlah, kategori, dan tanggal).

📌 3.3 add_transaction_screen.dart

Halaman form untuk mencatat transaksi baru. Di dalamnya terdapat validasi form, serta penggunaan Navigator.pop yang dieksekusi untuk menutup form dan kembali ke Dashboard setelah tombol Simpan diklik.

📌 3.4 transaction_detail_screen.dart

Halaman yang bertugas menerima passing data via Constructor. Variabel penampung diatur sebagai final dan required untuk menjamin data judul, nominal, kategori, dan tanggal transaksi berhasil ditampilkan ke antarmuka pengguna.

✅ BAB IV: Kesimpulan

Melalui praktikum ini, navigasi pergerakan antar layar dalam pengembangan Flutter berhasil dipahami secara menyeluruh. Pendekatan Navigator.push dan Navigator.pop memberikan kontrol penuh atas alur perjalanan pengguna secara efisien. Di samping itu, pengiriman data lintas halaman menggunakan Constructor dengan parameter required terbukti sangat andal dalam merender informasi dinamis antar layar, menciptakan pengalaman sistem yang terintegrasi dan responsif.
